# Nice Tea Hub

花茶、枸杞与天然植物茶的批发型 React + Vite 店铺演示。

## 已包含

- 5 个采购类目、50 个不重复的本地 WebP 商品资产。
- 批发价格区间约 $30–$100，按批发箱采购。
- `Add to Cart` 自动打开购物车侧栏；`Buy Now - $价格` 加入后直接进入结算页。
- PayPal、Visa / 信用卡支付选项与支付跳转演示入口。
- 采购政策、17 部分 Terms of Service 导航、隐私与 DMCA 页脚入口。
- `/` 商城、前端演示后台登录页面（点击头像进入）。

## 本地运行

```bash
npm i
npm run dev
```

生产构建：`npm run build`。
